## 上下文

- 删除目标仅为 `compiled-legacy-dom.ts` 的 `export const vapor = ... => _$compiledRoot(...)`。不得删除 `runtime-core` 中的 `RueRuntime.vapor`、`mountVapor`、协议 discriminant 或 Vapor entry。

## 测试计划

- 行为：公开给编译器的内部入口不再导出 `vapor`，现有编译根挂载、嵌套、SSR、KeepAlive、Teleport 与卸载行为保持不变。
- 失败验证测试：增加内部导出契约断言，要求 `vapor` 不存在且 `_$compiledRoot` 存在；现有行为测试改用 `_$compiledRoot` 后先在旧导出结构下验证契约失败。
- 失败验证命令：`pnpm vitest run packages/runtime/__tests__/runtime-architecture.spec.ts`
- 预期失败原因：`compiled-legacy-dom.ts` 与 Rue compiler internal 仍导出 `vapor`。
- 通过验证命令：`pnpm vitest run packages/runtime/__tests__/component.renderable.spec.tsx packages/runtime/__tests__/keepAlive.renderable.spec.tsx packages/runtime/__tests__/renderAnchor.component-replacement.spec.tsx packages/runtime/__tests__/server.ssr.spec.ts packages/runtime/__tests__/teleport.nestedVaporAnchor.spec.ts packages/runtime/__tests__/template.renderable.spec.tsx packages/runtime/__tests__/useComponent.spec.ts packages/server-renderer/__tests__/server-renderer.spec.tsx`
- 模拟策略：使用真实 DOM 测试环境与 server renderer，不模拟 compiled root。

## 步骤

1. 添加内部导出契约的失败验证，并把明确代表 compiled root 的测试 helper 改名为 `_$compiledRoot` 或语义化局部别名。
