## 上下文

- 新架构不允许运行时 JSX 或 `render(unknown)`；应用启动必须引用编译生成的 ComponentFactory/BlockFactory。
- 未经过 Rue 编译器的 JSX/TSX 应在构建时产生明确诊断。

## 测试计划

- 行为：标准应用入口编译为最小 mountApp 调用；缺失插件、运行时 JSX、动态任意 render 均构建失败。
- 失败验证测试：增加 bootstrap 输出快照和 Vite fixture 构建测试。
- 失败验证命令：`pnpm --filter @rue-js/vite-plugin-rue test && pnpm --filter @rue-js/swc-plugin-rue test`
- 预期失败原因：当前入口仍调用 createRue/render 并允许 jsx-runtime 创建运行时值。
- 通过验证命令：同上，并构建最小 Vite fixture。
- 模拟策略：使用真实 Vite build 和 SWC wasm，不模拟插件管线。

## 步骤

1. 先添加 compiler-required 与 bootstrap 失败测试。
2. 编译应用根为显式 mount factory 和 dispose handle。
3. 让 jsx-runtime 只提供编译标记/开发错误，不创建 renderable。
4. Vite 插件检测遗漏编译的 JSX 并失败。
5. 保证 app helper 仅依赖 block/dom/reactive 最小入口。
