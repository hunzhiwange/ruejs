## 上下文

- 当前 builtin 单文件超过 1000 行并依赖 compiled-component、render-anchor 与完整 reactive 链。
- builtin 子节点已是 BlockFactory；专用 runtime 只应管理目标节点、阶段、缓存或异步边界。

## 测试计划

- 行为：Teleport 移动、Transition 生命周期/取消、TransitionGroup keyed 移动、KeepAlive 缓存、Suspense resolve/reject 正确。
- 失败验证测试：每个 builtin 独立消费包不得包含其他 builtin 或通用 component/renderable runtime。
- 失败验证命令：`pnpm exec vitest run --project unit-jsdom packages/runtime/__tests__/compiledBuiltinsAsync.spec.ts packages/runtime/__tests__/teleport.renderable.spec.tsx packages/runtime/__tests__/transition.component-regression.spec.tsx packages/runtime/__tests__/keepAlive.renderable.spec.tsx packages/runtime/__tests__/suspense.renderable.spec.tsx`
- 预期失败原因：当前 builtins 聚合并经通用组件/anchor 挂载。
- 通过验证命令：迁移后的同等 compiled 行为测试；旧 renderable 测试须改为编译 fixture 而非保留兼容协议。
- 模拟策略：真实 DOM、timer 与 Promise；仅对 animation frame 使用可控时钟。

## 步骤

1. 为每个 builtin 建立独立生成快照和消费包失败门禁。
2. 编译 builtin props 与子块为专用 helper 参数。
3. 将共享逻辑限制为 block range/owner，不复建 component facade。
4. 删除 Template 的 runtime component 形态；模板仅是编译器语法结构。
5. 删除聚合 builtins 实现和旧 renderable 测试语义。

## 验证

- 运行：`pnpm --filter @rue-js/swc-plugin-rue test`
- 运行：上述迁移后测试命令。
- 运行：`node scripts/compiler-only-runtime-audit.js --scenario teleport --scenario transition --check`
- 预期：Teleport/Transition 各 ≤12 KB gzip，无其他 builtin 和禁止模块。
- 所需证据：每项行为、生成 import、模块列表、体积及删除清单。
