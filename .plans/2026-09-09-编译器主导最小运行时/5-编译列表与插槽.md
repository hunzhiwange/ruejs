## 上下文

- 编译器知道 row key、节点结构和 slot factory；runtime 只需 keyed order、owner/dispose 与区间移动。
- 禁止 row 或 slot 返回任意对象、Node/数组混合协议及 legacy reconciliation。

## 测试计划

- 行为：插入、删除、重排、更新和 slot 替换使用 closed Block ABI，保持节点身份。
- 失败验证测试：新增任意 renderable 被编译拒绝、合法 row/slot 不导入 render-anchor 的断言。
- 失败验证命令：`pnpm exec vitest run --project unit-jsdom packages/runtime/__tests__/compiledKeyedList.codegen.spec.tsx packages/runtime/__tests__/compiledNativeRowPatch.spec.tsx packages/runtime/__tests__/compiledEventsAndRefs.spec.tsx`
- 预期失败原因：当前 mount/slot/list 仍接受兼容 handle 与通用值。
- 通过验证命令：同上，并运行 SWC list/slot 测试。
- 模拟策略：真实编译产物与 DOM 身份断言。

## 步骤

1. 先锁定 keyed 操作和 slot 生命周期行为。
2. 统一 row/slot 为编译生成的 BlockFactory。
3. 保留最小 keyed 索引算法，删除 legacy list 和 value normalization。
4. 让 list 入口不依赖 component、Island、facade 或 render-anchor。
5. 达到 list gzip ≤5 KB，若已低于则收紧至当前值。
