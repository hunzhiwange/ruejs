## 上下文

- 支持 `=`, `+=`, `++/--`, `delete` 以及受控数组 mutator；每个左值与动态 key 只求值一次。
- 对状态对象整体传入未知函数、写入解构别名、`Object.defineProperty` 等不支持路径发出带源码位置的编译错误，不提供 Proxy fallback。

## 测试计划

- 行为：各种写法精确更新且一次求值；1 万项数组单项修改不复制整数组；不支持的逃逸稳定报错。
- 失败验证测试：新增赋值运算、动态 key 副作用、数组 push/splice/sort、delete 和逃逸诊断测试。
- 失败验证命令：`cargo test --manifest-path packages/swc-plugin-rue/Cargo.toml state_path && pnpm exec vitest run packages/runtime/__tests__/compiledStateMutation.spec.tsx --project unit-jsdom`
- 预期失败原因：写入仍依赖原生对象/Proxy，编译器没有路径写 helper 和逃逸诊断。
- 通过验证命令：同失败验证命令。
- 模拟策略：真实编译产物、真实 Signal/Graph 和数组，无 mock。

## 步骤

1. 先覆盖所有支持写法与明确禁止形态。
2. 增加 set/update/mutate/delete 的紧凑 compiler ABI。
3. 实现保持 JavaScript 求值顺序的左值改写。
4. 实现受控数组变异及路径触发范围；删除数组复制路径。
5. 增加逃逸诊断并运行大数组基准。
